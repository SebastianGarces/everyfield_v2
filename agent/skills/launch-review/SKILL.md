# Launch review

"Where are we on launch?" is an overview, not merely a request for the launch date. Read `launch.query` status for the date and completed/open/total milestone counts, then the open milestones and relevant task blockers, open ministry roles and upcoming meetings through `tasks.query`, `teams.query` and `meetings.query`. `intelligence.query` can add existing assessment evidence when useful. Code mode can combine independent reads.

Start with a useful narrative before any cards: the date or time remaining, progress out of the total, the most important open work, and supported implications. Select cards to support that explanation. An open-only query counts remaining milestones, not all tracked milestones. Read task assignees and due dates before suggesting missing owners or dates. Do not repeat opaque readiness scores from assessment data; explain a documented measure in ordinary language only when relevant. Do not replace the whole overview with a one-record launch-status card.

Missing outcome notes, launch-day attendance or a historical assessment do not erase the milestones, staffing and preparation records that are available. Name missing evidence briefly only where it limits a conclusion. Avoid diagnosing overall church health or spiritual readiness.

Read further pages or counts before claiming complete staffing and milestone totals. Distinguish a milestone blocked by a prerequisite from one merely unfinished. For follow-up action requests, carry the selected evidence into `actions.prepare` rather than silently changing the launch plan.
