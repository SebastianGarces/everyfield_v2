Rule Where it lives
Banned verdict verbs for the network audience: intervention, failing, critical, lack of (+ "needed to" framings). Rubric text and a structural check: a post-generation validation scans network-audience insight text for the ban-list; a hit is a retry, never a stored insight.
Same-concern pairing: every network observation has a planter observation on the same underlying concern (different wording is fine). Rubric rule + zod refinement: each network insight's category must also appear among the planter insights. Retry on violation.
Pattern, not cause: network copy names the measured pattern + "may be worth a coaching conversation"; a cause is named only when it is a measured fact. Rubric rule; the planter-side gets the opposite guidance — show contributing signals ("growth stalled; two contributing signals are vision cadence and stale follow-up") so the planter has the explanation before elders raise it.
